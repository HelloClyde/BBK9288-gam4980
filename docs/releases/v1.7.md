# v1.7

本版汇总 v1.6 之后的执行引擎、原生 HLE、NAT 和绘图优化，采用用户确认的四灰阶 BBK 学习机图标。用户真机反馈性能已可接受；不承诺所有游戏满速。

## 主要变化

- IRAM 汇编解释核、共享寄存器调用及 bank/ROM cache 索引优化。
- 原生运行库、绘图和文字函数按需装载，合并重复 HLE 算法。
- 绘图边界批量提交，修复持久白线，减少逐 tile 展示。
- 加载阶段文本提示、最新一段性能日志和宿主耗时归因。
- 修复 CI 的生成头文件同步及关闭可选功能时的编译兼容问题。

## 安装

建议下载 `bbk9288-gam4980-player-v1.7.zip`，按目录复制到存储盘：

- `系统/程序/GAM4980.exe`
- `gam4980/GAM4980.NAT`
- `gam4980/8.BIN` 和 `gam4980/E.BIN`

升级时同时替换 EXE 和 NAT，保留自己的游戏和存档。单独下载 EXE 仅适用于已经安装本版配套 NAT 的情况。
压缩包不包含《伏魔记》或其他 GAM 游戏、存档、SDK。

发布二进制沿用真机确认的执行载荷，仅更新确认的图标；CI 修正不引入新的性能实验。

## 已知限制

- 速度因游戏和场景而异，加载与原生匹配仍可能耗时。
- 三国霸业启动图像的旧有兼容问题尚未解决，不列为已验证可玩。
- CI 是宿主编译与核心 smoke 检查，不替代全部游戏的真机验证。
