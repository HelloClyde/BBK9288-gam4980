# 固件 bank 查询整函数 HLE

## 范围与契约

`E.BIN` 物理 `$EAA4A5–$EAA4F3`，虚拟 `$F4A5–$F4F3`。
这是当前 bank 到逻辑 bank 编号的换算函数，不是游戏专属函数，也不是 `$F52A` 的 bank 写入函数。

完整入口 `$F4A5`；另支持已执行 prologue 的 `$F4AD`（要求 A=5）和 `$F4AF`（要求当前选择器=5）恢复入口。

函数保存 P/X/Y，选择 bank 5，比较 bank 高字节与 `$03D5`，选择 `$03D6/$03D5` 或 `$2029/$202A` 基址。结果为 16 位模减法后右移两位，加分支偏置 0 或 `$E0`，取低字节。保留两次 `$2000` 写入，恢复 X/Y/P，通过 A 返回结果并 RTS。真实栈字节写入与选择器写入保留。

由于尾部 PLP 恢复 flags，原生实现不维护不被外部观察的中间算术 flags。没有跳过可观察的 bank 选择副作用。

完整函数对应 108/110 客机周期；两个恢复入口分别扣除已执行的 17/20 周期。预算不足、十进制模式、错误 bank、错误后缀条件或函数指纹不匹配时回退。

首次使用验证固定固件映射与函数双哈希：FNV32 `3AE34DC8`，SDBM32 `2300C3E1`。验证不依赖 GAM 文件名或整个游戏签名。使用此固件路径的其他游戏可共用，但收益仍取决于实际调用频率。

## 测试

- `tests/firmware_hle_bank_query_test.c`：3 个入口各 10000 组 CPU/全部 RAM/bank 表/选择器/周期差分通过；包含全部栈指针位置、随机寄存器和基址。
- 另对 16 组完整入口状态扫描预算 1..108，共 1728 组短预算差分通过。
- 主机测试使用 C 原解释路径作为参考，不把主机耗时当作真机收益。
- 19 项 `test_s6502*.py` 通过。全套 128 项运行有取消子进程测试失败和临时日志占用清理错误，另跳过 15 项；不能声称本轮全套通过。
- 新 KF2 使用 9288 SDK 编译，IRAM 保持 5284 字节，没有扩大热核。新 NAND 镜像安装前核验 EXE 哈希。
- 模拟器文件选择、启动、开场剧情通过；QMP 读取新 ELF 中计数器，查询 HLE 命中 4588 次，证明游戏实际进入该路径。没有进行完整游玩或退出回归。

日志新增 `firmware_bank_query_hle_hits` 与 `firmware_bank_query_hle_guest_cycles`，后者是省去解释的客机周期，**不是宿主耗时**。旧 bank-switch 诊断桶目前也包含本函数；专属字段用于区分。
