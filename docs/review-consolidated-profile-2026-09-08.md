# 合并优化与一次运行诊断

目标：减少真机反复换包测试。模拟器负责功能等价与边界，真机只负责最终性能确认。

## 改动

- NAT 函数按稳定 manifest 索引记录物理入口、采样调用次数、接受次数、独占宿主 ticks。192 项使用 3072 字节外部 RAM，不占 IRAM。
- 复用每 16 个执行片段一次的现有采样时钟，不为函数榜额外读时钟。文件读取阶段不归给调用者。嵌套原生函数分别归因。
- 去掉绘图旧计时器重复的开始/结束时钟读取。`native_graphics_version=2`，耗时改为采样独占时间，不能直接与旧版包含下游耗时的字段比较。
- LDA/LDX/LDY/ORA/AND 零页读取使用专用路径；$00..$03、$0c..$0e 仍回退，其他地址与原通用读路径一致。无需计算高页号和查询页表。
- 新增 `tools/analyze_host_profile.py`，自动选择最后一个完整日志，保留重复函数记录，按累计独占时间排序而不是调用次数。

## 日志口径

每组 `nat_sample_pc / nat_sample_attempts / nat_sample_accepted / nat_sample_exclusive_ticks` 描述一个 NAT 入口。PC 是十进制物理地址，分析工具同时输出十六进制。它们全是**采样值**。

256 Hz 计数器分辨率约 3.9 ms，零 ticks 不表示免费；短函数需要积累样本。固定间隔采样也可能与客机工作节奏相关，不能据此承诺精确百分比。寄存器 ABI 叶函数仍归入 IRAM 阶段，未单独读取时钟。阶段之和不是整个会话时长，禁止直接除以 RTC 会话时间计算覆盖率。

使用方式：`python tools/analyze_host_profile.py PERF.LOG`。无需手工截取最新一段。

## 验证

- 宿主测试覆盖跨阶段嵌套、函数独占时间、排除 IO、时钟回绕；日志分析覆盖重复字段及不完整尾段。
- 实际模拟器确认函数记录产生，NAT 图形/文字被执行，LCD 76800 像素与客机 RAM 展开结果一致。
- 零页新增 S1C33 测试遍历五种 opcode × 256 地址，检查寄存器、flags、PC、cycles、特殊地址回退与 RAM 不变。

最终结果：16/16 组 S1C33 等价测试通过（含 1280 个零页子用例），IRAM 从 5516 缩为 5364 字节。完整《魔塔》运行并退出回桌面；从退出后的模拟器 NAND 提取 PERF.LOG，自动解析得到 33 个实际 NAT 函数记录。该模拟器样本总计仅 2 个采样 ticks，不能作为真机热点排序结论。
